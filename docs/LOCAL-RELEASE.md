# პირველი ადგილობრივი ვერსია — გაშვება და დასრულების საზღვარი

პაკეტის ვერსია: **0.1.0**. სამუშაო branch: `feature/product-research-automation`.
გამოყენება: ერთი მფლობელის პირადი კვლევა ლეპტოპზე, ლოკალური PostgreSQL-ით.

## რას ნიშნავს ამ ვერსიის დასრულება

პროდუქტის შემოტანა/მოძებნა, შენახვა, მიწოდების შეფასება, კონკურენტისა და
წყაროების დამატება, ხარჯების დათვლა, შენახულ წყაროებზე AI კვლევა და ანგარიშის
ჩამოტვირთვა ფუნქციონირებს შემოწმებული სცენარების ფარგლებში. უცნობი მონაცემები
და პროვაიდერის შეფერხება ცხადად უნდა გამოჩნდეს. ფაქტობრივი კვლევა, გაყიდვები და
მომწოდებლის იდენტურობა კონკრეტულ პროდუქტზე ცალკე სამუშაოა.

ეს არ არის ავტომატურად ინტერნეტში მოთხოვნის აღმომჩენი/მომგებიანი პროდუქტების
გარანტირებული ამრჩევი სისტემა. AI შენახულ მონაცემებს აანალიზებს. eBay-ის რეალური
აქტივაცია ანგარიშის დამტკიცებამდე გამოტოვებულია; ხელით კვლევა მუშაობს.

## ჩვეულებრივი გაშვება Windows CMD-ში

```cmd
cd C:\Users\temof\arbitrage-finder-local
npm run dev -- --hostname 127.0.0.1
```

გახსენი http://127.0.0.1:3000. ტერმინალი დატოვე ჩართული. Ctrl+C აჩერებს აპს.
PostgreSQL-ის სერვისიც გაშვებული უნდა იყოს. pgAdmin მხოლოდ მართვის პროგრამაა.
ახალი ინსტალაციისთვის გამოიყენე [LOCAL-SETUP.md](LOCAL-SETUP.md).

## განახლება

გაშვებულ აპზე Ctrl+C, შემდეგ იმავე საქაღალდეში:

```cmd
git pull --ff-only origin feature/product-research-automation
npm run dev -- --hostname 127.0.0.1
```

ბრაუზერში Ctrl+F5. ამ დასრულების ცვლილებას ახალი dependency ან მიგრაცია არ აქვს.
თუ მომავალში package-lock შეიცვალა, გაჩერებულ აპზე საჭიროა `npm ci`.
ბაზის ცვლილება ცალკე უნდა აიხსნას და დამტკიცდეს; `prisma migrate reset` არ გამოიყენო.
თუ Git ადგილობრივ ცვლილებებზე ან კონფლიქტზე გაჩერდა, არ წაშალო ფაილები და არ
გაუშვა force/reset — ჯერ შეინახე შეტყობინება განსახილველად.

6. AI კვლევაში გადაამოწმე პაკეტი და შესაძლო ხარჯის თანხმობა; წარმატების შემდეგ
   დასკვნები შეადარე მისივე შენახულ წყაროებს. მოთხოვნისას დაელოდე ორ წუთამდე.

## პრობლემისას

- AI კონფიგურაცია: პროდუქტის AI გვერდის ოთხი შემოწმება, შემდეგ აპის restart.
- Timeout: კვოტის ამოწურვას არ ნიშნავს; ავტომატური retry არ არის.
- 401/403/404/429/5xx: შესაბამისი განმარტება წაიკითხე; განმეორებითი მცდელობები
  მიზეზის დადგენამდე არ დახარჯო. გასაღები/პაროლი ჩატში არ გამოაგზავნო.
- eBay approval-ზე ლოდინი: გამოიყენე ხელით competitor entry ან ნებადართული JSON.
- CJ მხარდაჭერა/მწარმოებელი უცნობია: შესაბამისობა UNCERTAIN, ხარჯები UNKNOWN.
- Environment Publish შეცდომა GitHub-იდან ლეპტოპის განახლებას არ ბლოკავს.
